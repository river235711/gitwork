Our services

Covering every critical step from PDK bring-up to physical signoff, as a one-stop technical consulting partner.

PDK Development & Porting

CDF setup and callback development, process porting, SKILL development, and PCELL customization across TSMC, UMC, SMIC, GF, and HLMC foundry formats — accelerating PDK bring-up, QA, and cross-node migration.

  • CDF / Callback
  • Porting
  • SKILL Coding
  • PCELL Coding

Tools: Virtuoso

Verification

Full-spectrum verification including DRC, LVS, RC extraction, and EMIR analysis, plus PGV library flow setup, to ensure design-rule compliance and power integrity.

  • DRC
  • LVS
  • RC
  • EMIR

Tools: Calibre, PVS, StarRC, QRC, Voltus

Physical Design

Innovus-based APR support across the netlist-to-GDSII flow: floorplanning and power planning, placement, clock tree synthesis, global and detailed routing, timing and PPA closure, ECO implementation, and physical signoff.

  • Floorplan
  • Power Plan
  • Placement
  • CTS
  • Routing
  • Timing Closure
  • ECO

Tools: Innovus, Genus, Tempus, Voltus, Quantus

CAD Support

SPICE model evaluation and EDA tool qualification, plus automation flows, version control, and benchmarking that keep the design environment qualified, scripted, and reproducible.

Model & tool certification

  • Model Evaluation
  • Tool Qualification
  • Benchmark

Automation & scripting

  • Perl
  • Tcl
  • Python / Tk
  • SVN
  • GIT
  • LSF

Tools: ADE, Spectre

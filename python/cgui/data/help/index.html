01 Home & Workspace Overview

When PVFlow launches, the Home tab displays the available Tools tiles and provides direct access to every application in a tabbed environment:

Tools Tiles on Home

  • DRC (DRC Verification): Opens the DRC runner tab (LayoutPath, LayoutPrimary, CmdFile, RunFolder).
  • GdsViewer (KLayout GDS): Opens the standalone GDS/OASIS cell scanner and KLayout launcher.
  • LVS / XRC: Custom on request — Cadsemi can customize LVS and XRC workflows upon customer request (support@cadsemi.com).
  • Help (User Guide): Opens this offline User Guide in your web browser (F1).

Quick Navigation

  • Press + in the tab strip or Ctrl+T to open a new Home tab.
  • Use File → Recent Runs to reopen previously remembered DRC sessions.
  • Use License → License Info... at any time to inspect license details.

03 Tabs, New Window & Recent Runs

  • Dynamic Tab Strip: Each open tool tab displays a close button (×). Opening many tabs compacts tab widths smoothly, while the + button creates additional Home tabs.
  • File → Recent Runs: Remembered DRC runs (layout file & rule/command mode) appear in the File → Recent Runs submenu. Select an entry to reopen it directly in a tab, or click Clear Recent Runs to reset history.
  • Multiple Windows: Use Window → New Window (Ctrl+N) when you want side-by-side PVFlow windows on multi-monitor desktops.

04 DRC Workspace Setup

Open DRC from the Home tile grid or via Tools → DRC Verification.

FieldPurpose & Behavior
LayoutPath Select your input .gds or .gds.gz layout file. PVFlow resolves relative paths and assists in filling LayoutPrimary when choosing a layout file.
LayoutPrimary Top cell name in the layout used for hierarchical DRC checking.
CmdFile Select or manage your DRC rule / command file.
RunFolder Target directory where DRC run scripts, transcripts, and result databases are generated.
Tip: When reusing an existing deck with File → Open Cmd..., PVFlow normalizes relative ../ includes so your command file runs reliably from the chosen RunFolder, and automatically manages DRC ICSTATION YES settings when configured.

06 GDS Viewer: Opening Layouts & Scan Cells

Open GdsViewer from the Home tile grid or Tools → GDS Viewer. GdsViewer lets you inspect .gds, .gds.gz, .oas, and .oasis layouts in KLayout without running DRC first.

  1. Select the layout file in LayoutFile.
  2. Click Scan Cells to inspect cell names directly inside binary .gds / .gds.gz files using PVFlow's built-in pure-Python GDSII scanner (no external Python GDS packages required).
  3. Double-click or select a cell from the cell list to pass that TopCell directly to KLayout, or click Open KLayout to launch KLayout.

07 Layermap Conversion (.layermap → .lyp)

If your PDK provides a Virtuoso/EDA .layermap file instead of a KLayout .lyp layer-properties file, you can supply either format in GdsViewer:

  • Providing an existing .lyp file passes it directly to KLayout (-l <file.lyp>).
  • Providing a .layermap file triggers PVFlow's built-in layermap_to_lyp converter, automatically generating a ready-to-use KLayout .lyp palette with layer names, layer/datatype pairs, colors, and stipple patterns before launching KLayout.

08 KLayout Resolution Priority

Both GdsViewer and the DRC View button locate the KLayout executable in strict order:

  1. PVFLOW_KLAYOUT environment variable: Explicit path set by the user or CAD environment wrapper.
  2. System PATH (klayout): Pre-installed customer KLayout on the workstation or via environment modules.
  3. Bundled fallback (tools/klayout): Optional self-contained fallback location inside the PVFlow installation directory.

11 License & CLI Reference

PVFlow verifies its signed license at startup without needing an external flexlm daemon.

pvflow           # Standard launch (checks CADSEMI_LICENSE_FILE and upward license paths)
pvflow -L        # Print license status and details
pvflow -l        # Machine chooser (LOADING) only
pvflow -e -h     # Engineer CLI mode options
  • Quick Trial Setup: Place cadsemi.lic directly in /apps/cadsemi/license/cadsemi.lic, /apps/cadsemi/pvflow/cadsemi.lic, or inside the extracted version directory (e.g. 26.11.001/cadsemi.lic) to start without setting environment variables.
  • Environment Variable: Set CADSEMI_LICENSE_FILE=/path/to/license.lic in your shell startup or modulefile.
  • Normal Valid State: Keeps the workspace uncluttered with no persistent bottom bar; inspect full details anytime via License → License Info....
  • Expiring / Grace / Invalid States: Displays a warning banner at the bottom of the window so administrators can renew or select a new .lic file via License → Select License File....

12 Support & Troubleshooting

  • Browser did not launch on F1: PVFlow tries PVFLOW_BROWSER (if set), then google-chrome, chromium, chromium-browser, xdg-open, firefox, and Python's webbrowser fallback. On minimal headless/VNC servers, verify one of these browsers is in PATH or open data/help/index.html directly.
  • KLayout not found: Ensure klayout is on PATH, set PVFLOW_KLAYOUT=/path/to/klayout, or place the binary at <version>/tools/klayout inside the PVFlow installation directory.
  • Customer Support: Email support@cadsemi.com or visit https://cadsemi.com.

# Machines the LOADING tab watches, one per line ('#' starts a comment).
#
# Each is probed with
#     ssh -o BatchMode=yes -o ConnectTimeout=3 <host> '<read /proc>'
# except the machine cgui itself runs on, which is read directly. So a host
# listed here needs passwordless ssh from wherever users start cgui;
# one that does not answer is shown as such rather than holding up the others.
#
# A machine that can only be reached through another one gets a route:
#     <host> via <user@jumphost>
# which becomes `ssh -J <user@jumphost> <host>` -- one command, no logging in
# twice, and the display still comes back to where cgui is running. Put the
# login in front of the host name if it differs there too: user@host via ...
# Put one host name per line when enabling multi-host monitoring, e.g.:
# host01
# host02
